## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch uses non-destructive patching methods that only modify application-specific configuration files, not system files. It is designed to be undetectable by standard anticomponent software and leaves no residual tool.

### Which operating systems are supported?

OmniPatch is a Windows desktop application. It supports Windows 10 and Windows 11. We are considering a macOS version for future release.

### How often is OmniPatch updated to support new app versions?

The development team monitors updates for all supported applications and releases a new OmniPatch version within 48-72 hours of any major change that might affect activation.

### Can I use OmniPatch commercially or for my team?

OmniPatch is intended for personal use and evaluation. We do not provide licenses for commercial or team deployment. Please review the terms of service for target applications.

### Will using OmniPatch violate the terms of service of these AI apps?

Yes, using OmniPatch to activate premium features without a valid subscription will violate the terms of service of the respective applications. Users assume all responsibility.

### Does OmniPatch require an internet connection?

An initial internet connection is required to download the patcher and potentially verify some configurations. Once activated, most premium features can be used offline where the original apps support it.

### What if an application update breaks the patch?

The tool includes an auto-update checker. If a patch is broken, simply re-run the latest version of OmniPatch, and it will apply a new patch for the updated application.

### How do I know which features are unlocked?

After running OmniPatch, open your target AI application and navigate to the subscription or account page. Premium features should now show as active or unlocked.
